## 一、框架介绍

VideoPipe 是一个用于视频分析和结构化的C++框架,具有以下特点:

1. 管道式架构

- 采用管道(Pipeline)设计模式,将视频处理分解为多个独立节点
- 节点之间通过数据流进行连接,形成完整的处理流水线
- 支持灵活的节点组合与拆分

2. 节点类型

- 源节点(Source Node): 负责视频输入,如文件、RTSP流等
- 推理节点(Infer Node): 执行AI推理任务,如目标检测、分类等
- 跟踪节点(Track Node): 实现目标跟踪
- 行为分析节点(BA Node): 分析目标行为
- 显示节点(OSD Node): 叠加显示处理结果
- 目标节点(Des Node): 负责结果输出,如屏幕显示、视频保存等

3. 数据流

- 帧元数据(Frame Meta): 包含图像数据及处理结果
- 控制元数据(Control Meta): 用于节点间的控制信息传递
- 支持多路数据流并行处理

4. 扩展性

- 基类设计合理,易于扩展新的节点类型
- 支持自定义数据处理逻辑
- 支持动态调整管道结构

5. 其他特性

- 支持GPU加速(CUDA/TensorRT)
- 支持多种深度学习框架(OpenCV DNN/PaddlePaddle等)
- 内置丰富的示例代码
- 完善的日志和调试功能
